# DigitalLab SOP 文件格式 v1

文件为UTF-8 JSON（允许UTF-8 BOM），扩展名 `.json`，最大1MB。只接受规定字段，多余字段会报错。每个SOP的标题、步骤及正文均为中文可读内容；`id` 使用稳定英文标识。

| 字段 | 类型与用途 |
| --- | --- |
| format | 固定字符串 `digitallab.sop` |
| schemaVersion | 固定数字 `1` |
| device | `{name, model, code}`，标识目标设备；name必填，其余未知可空 |
| precautions | 全设备共用的使用前提示，Markdown字符串 |
| labelTips | 最多2条纯文本，每条1–32字；不印提示时 `[]` |
| sops | 1–20套使用方式 |

每套SOP必须包含以下所有字段：

| 字段 | 限制 |
| --- | --- |
| id | 1–64位小写字母、数字、`-`、`_`，首位为字母或数字；文件中不重复 |
| name | 使用方式名称，1–120字；文件中不重复 |
| version | 版本字符串，最多200字；未定时空字符串 |
| applicability | 适用样品、任务与排除范围，最多2000字 |
| precautions | 本方式专有的使用前提示，Markdown，最多16000字 |
| steps | 1–100个 `{title, body}`；title为1–120字，body为1–16000字Markdown |
| sources | 最多30个 `{title, url, locator}`；标题必填，URL仅http/https或空，locator为版本/页码/章节 |
| reviewNotes | 最多30条待核对事项，每条1–1000字；全部已核对时空数组 |

顶层 `precautions` 最多16000字。设备name最多120字，model最多200字，code最多40字。来源title最多200字、url最多2000字、locator最多200字。长度按JavaScript UTF-16计数，普通中文字为1，emoji可能为2；不要使用非必要emoji。

## 导入语义

- 文件不会修改设备名称、型号、购买资料、发布状态或二维码。编号与当前档案不一致时禁止导入；名称或型号不同会提醒核对。
- 合并模式：相同id更新整套SOP，其他现有SOP保留，新id追加。合并后仍须名称唯一、最多20套。
- 替换模式：当前全部SOP被文件中的SOP替换；预览会列出将移除的方式。
- 两种模式都会将通用使用前提示与标签短提示替换为文件内容，包括空字符串或空数组；必须在预览中检查。
- 确认导入只修改编辑表单，保存档案后才生效。文件本身不会被公开作为附件；已发布设备保存后的SOP文字可供访客查看，因此正文与来源不得包含内部购买信息或保密内容。
- 旧版单一SOP会显示为“通用操作”，标识为 `legacy-default`；更新时可沿用此标识。
